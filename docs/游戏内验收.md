# 《蘇清的训练假人》游戏内验收

测试目标为 Project Zomboid 42.22.2 单人模式。请在新建的隔离测试档中操作。每个用例可在技能面板记录训练前后的经验，并通过右键菜单查看假人状态。

## 普通视角

1. 只在测试档启用 `SuQingTrainingDummy`。在原版建造菜单找到「训练假人」，核对材料和工具提示，旋转预览并在空地建造。检查四个朝向的贴图、落地位置与占地，材料只扣一次，工具仍在背包。
2. 用斧、棒球棍、锤子、砍刀、猎刀和长矛各命中一次，观察相应技能增长及假人耐久每次减少 1。再用削皮刀或破玻璃瓶等对门伤害为零的武器确认仍固定减少 1。站远、转身、隔墙、挥空、推搡或打旁边家具，观察训练经验保持原值。把两只假人相邻放置，确认一次挥击的结算情况。
3. 右键检查耐久。带材料修理，检查物品只扣一次且工具保留。取消修理、在排队后离开目标或移走材料，再检查扣料和耐久。
4. 记下耐久和技能经验，保存后重新进入。查看假人位置、朝向、耐久和经验，再次攻击确认还能结算。另用一只假人测试最后一击和耗尽耐久后的移除。

## Viewpoint

1. 保持测试档的主模组启用，加入 `Viewpoint` 和 `SuQingTrainingDummyViewpoint`，重启游戏。用同一只假人对比普通视角和 Viewpoint。
2. 从四面观察胸口靶环、包布、木架和落地位置，比较旋转后的方向。移开再走近，查看模型卸载和重新加载时的表现。
3. 分别用近战攻击和右键修理。保存重进一次，然后将测试档的配套模型停用并再次检查同一假人的普通视角贴图和耐久。

## 试验性枪械

1. 在测试档开启「试验性枪械训练」。距假人 4–6 格，同层无遮挡，用原版手枪瞄准胸口开一枪。观察弹药、瞄准经验和耐久。
2. 逐项测试空枪、拉栓、脱靶、隔墙、低于最短距离、楼层不同和其他目标挡在前面。连发与霰弹枪按每发比对经验。
3. 使用 Viewpoint 和 Modern Firearms System 时分别复测成功与失败用例。记录相机、武器、距离和技能经验变化。
