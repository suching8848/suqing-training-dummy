# 训练假人验证

## 0.1.0-rc.2

原版 `IsoThumpable` 扣耐久的 25 组数值读回通过。本机 Kahlua 通过 150 组武器分类、伤害和耐久组合，以及 8 项相关边界场景，覆盖最后一击、每次挥击的经验去重和普通家具。用户确认正式单人档测试正常。试验性枪械保持默认关闭，枪械模组和 Viewpoint 下的瞄准行为待验收。

## 0.1.0-rc.1

2026-11-15（北京时间）。基于本机 Project Zomboid 42.22.2、Steam build 26486631、游戏 revision 3d39148846，以及 Project Viewpoint 0.1.6.2。通过独立读取器和 Lua 模拟对象检查。

| 检查 | 结果 |
| --- | --- |
| 原版模组发现 | 主模组与 Viewpoint 子模组均识别为 `42` 分支。主模组注册 1 个纹理包和 1 个地块定义。子模组正确声明主模组与 `Viewpoint` 依赖。 |
| 原版建造及翻译读取器 | 45 项断言通过，覆盖建造消耗和工具保留、木工要求、300 点耐久、四方向单格建造、三项沙盒参数默认值、中英界面定义与翻译。CN/EN 共 18 个对应键及其占位符通过一致性检查。 |
| Lua | 4 个运行脚本通过本机 Kahlua 编译。Lua 5.1 模拟通过六类近战、攻击结束清理、误判、重复回调、零对门伤害武器、技能开关及维修扣料和重复完成。 |
| 枪械试验 | 同一组 40 个模拟场景在 Lua 5.1 和本机 Kahlua 通过，覆盖开火门槛、方向、遮挡、不同楼层、最近目标和单发去重。默认关闭。Lua 训练判定使用角色瞄线与假人胸部的几何范围。 |
| 贴图和模型 | 本机原版读取器解析 PZPK 和四张 128×256 RGBA 贴图，原版 `IsoWorld` 读回四方向和碰撞属性。Viewpoint 的 `ObjReader`、`PackManifest` 解析 776 个三角面、材质、512×512 贴图及四个方向绑定。 |

游戏内需验收实际建造、打击和维修、存档复读、两种视角的显示和点击，以及原版和模组枪械的训练判定。详见 [游戏内验收](游戏内验收.md)。
