# 蘇清的训练假人

[English](README.en.md)

在 Project Zomboid 的原版建造菜单造一只训练假人，用平时的攻击操作练习六类近战武器。有效命中将相应经验写入原版技能面板。面向 Build 42.22.2 单人模式。

| 模组 ID | 用途与前置 |
| --- | --- |
| `SuQingTrainingDummy` | 主模组。建造、近战训练、耐久和维修。使用原版 Lua 接口。 |
| `SuQingTrainingDummyViewpoint` | 可选三维模型，需要主模组与 `Viewpoint`。两种视角使用同一只假人。 |

## 游玩

1. 在建造菜单的「蘇清的训练假人」分类选择训练假人。需要木工 1 和一把锤子。建造消耗 4 块木板、6 枚钉子、4 份碎布，保留锤子。
2. 使用斧头、长棍、短棍、长刀、短刀或长矛命中假人。每次有效攻击默认增加 0.5 基础经验，按武器脚本的类别写入原版技能系统。实际到账受原版经验倍率影响。
3. 右键查看耐久。初始耐久 300，近战武器每次有效命中固定扣 1 点，归零时损毁。修理需锤子，并消耗 1 块木板与 1 份碎布，最多恢复 100 点耐久。

可在「蘇清的训练假人」沙盒设置调整每次近战攻击的基础经验。使用模组武器时，技能按武器实际声明的原版类别计算。

「试验性枪械训练」默认关闭。开启后，候选逻辑会在实际开火时用角色瞄线检测同层、相隔至少 3 格且无遮挡的假人。每发命中默认给 1 点基础瞄准经验。判定使用假人胸部的几何范围，原版的弹药消耗与枪声仍由游戏处理。枪械、第三人称瞄准和 Viewpoint 瞄准均待游戏内验收。

## 测试包

退出游戏后，将测试包中的两个模组目录放入用户数据目录的 `mods` 文件夹。在测试档启用主模组。使用 Project Viewpoint 0.1.6.2 时可一同启用配套模型。普通视角贴图随主模组加载。移除主模组前，可先在测试档打坏已放置的假人。
